    How it works

    {{ engines|length }} engines read the text

    Neural classifiers trained on AI text, statistical tests that measure how predictable each word is, and checks for the phrasing AI models overuse.

    One calibrated score

    The engines' votes are combined by a model fitted on SlopBench, so a score of {{ bands[2]|int }} means the same thing in every report: fewer than 2 in 100 human texts score that high.

    Every vote shown

    You see each engine's score next to the total. When the engines disagree, the report says so.
